# 六大期货交易所公告自动提醒

GitHub Actions 免费定时检查上海期货交易所、大连商品交易所、郑州商品交易所、中国金融期货交易所、上海国际能源交易中心、广州期货交易所的公告栏目，并通过 QQ 邮箱发送提醒。

## GitHub Secrets

- `SMTP_USERNAME`：发件 QQ 邮箱
- `SMTP_PASSWORD`：QQ 邮箱 SMTP 授权码（不是 QQ 密码）
- `MAIL_TO`：收件邮箱；多个地址可用英文逗号隔开

## 首次运行顺序

1. `test_email`：只测试邮箱连接。
2. `initialize`：保存当前公告作为基线，不发送旧公告。
3. 此后定时任务自动以 `monitor` 模式运行。

## 说明

- 检查频率约为每 15 分钟一次；GitHub 免费定时任务可能偶尔延迟。
- 北京时间工作日 17:35 发送日报。
- 若某一交易所网页改版，程序会在连续三次识别失败后发送故障提醒。
- 本项目不是交易决策系统；重要信息应以交易所官方原文为准。
